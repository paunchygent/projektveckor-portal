# Skill: docs-as-code (Projektveckor Portal)

The shared `agent-docs-governance` skill and its `projektveckor-portal.md`
reference own the docs-as-code workflow. This skill holds the portal's local
facts.

## Canonical files

- Entry docs: `docs/index.md` and the section `INDEX.md` files, generated by
  `pdm run docs-validate`; never edit them by hand.
- Portal overview (goals, architecture, content pipeline):
  `docs/reference/ref-portal-overview.md`.
- Active state: root `handoff.md` with `## Current`, `## Recent` and
  `## Facts`; check it with `pdm run handoff-validate`.
- Repo-local skills: `.codex/skills/`; `.claude/skills` and `.agents/skills`
  are links to it.

## Writing docs

- Scaffold new contracts and documents with `pdm run new-task` and
  `pdm run new-doc`; they use PROJV identity.
- Documents under `docs/backlog/`, `docs/decisions/`, `docs/prd/` and
  `docs/reference/` written before 2026-10-23 use the retired local contract
  and are history. Update a durable fact in the document or skill that owns it.
- Durable decisions go to an ADR in `docs/decisions/` or to the owning skill;
  there is no separate memory file.
